# AGENTS.md — Aniekan Udo Portfolio

## Project Overview

This is the automated portfolio site for **Aniekan Udo**, a Medical Student & AI Software Engineer specializing in Data, AI, Fullstack, MLOps, and Healthcare Technology. The site is built with Astro, styled with Tailwind CSS, and deployed to GitHub Pages via GitHub Actions.

**Key features:**
- **Projects** are automatically synced from GitHub repos listed in `projects.yaml`
- **Research** papers are auto-synced from repo READMEs following `RESEARCH_TEMPLATE.md`
- **Experience, Education, Skills, About** are config-driven via YAML files in `data/`
- **CI pipeline** fetches READMEs, thumbnails, research papers, and metadata at build time

**Sections:**
- **Hero** — Name, title, tagline
- **About** — Bio with photo
- **Skills** — Tech stack grid
- **Experience Timeline** — Professional journey with photos
- **Education** — Degrees and certifications
- **Research** — Auto-synced publications
- **Projects** — Filterable project grid

## Development Workflow

### Prerequisites

- **Node.js** 18+ and **npm**
- **Python** 3.10+ and **uv** (`pip install uv` or `curl -LsSf https://astral.sh/uv/install.sh | sh`)

### Initial Setup

```bash
# 1. Install Node dependencies
npm install

# 2. Create Python virtual environment and install deps
uv venv .venv --python 3.12
uv pip install -r scripts/requirements.txt --python .venv\Scripts\python.exe

# 3. Sync content (generates src/data/content.ts)
npm run sync:content

# 4. Sync projects (generates src/content/projects/*.md)
npm run sync

# 5. Sync research (generates src/content/research/*.md)
npm run sync:research

# 6. Start dev server (localhost:4321)
npm run dev
```

### Daily Development

```bash
# Sync all content
npm run sync:content
npm run sync
npm run sync:research

# Start dev server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```

### Python Environment Isolation

**Important:** All sync scripts run inside the `.venv` virtual environment.

- **Windows:** `.venv\Scripts\python.exe`
- **Linux/macOS:** `.venv/bin/python`

The `npm run` commands are pre-configured to use the correct path on Windows. On CI (GitHub Actions), it uses the Linux path automatically.

## Adding Content

### Projects

Edit `projects.yaml`:

```yaml
projects:
  - repo: Dr-Aniekan-Udo/your-new-repo
    category: "Fullstack"
    featured: true      # optional: highlights on grid
    priority: 1         # optional: sort order (lower = first)
```

**Project repo README:** Follow `PROJECT_README_TEMPLATE.md` for enhanced parsing.

Push to `main`. GitHub Actions will:
1. Create a fresh Python venv and install deps
2. Run `sync-projects.py` to fetch READMEs and thumbnails
3. Build the Astro site
4. Deploy to GitHub Pages

### Research Papers

**Option A: Auto-sync from repo (recommended)**

1. Create a research repo with README following `RESEARCH_TEMPLATE.md`
2. Add to `data/research.yaml`:
```yaml
research:
  - repo: "Dr-Aniekan-Udo/your-research-repo"
    autoSync: true
    featured: true
    priority: 1
```

**Option B: Manual entry**
```yaml
research:
  - title: "Paper Title"
    authors: "Author 1, Aniekan Udo, Author 3"
    venue: "Conference Name"
    arxiv: "xxxx.xxxxx"
    abstract: "Abstract text..."
    methodology:
      - "Step 1"
      - "Step 2"
    conclusion: "Results..."
    tags: ["Tag1", "Tag2"]
    featured: true
    priority: 1
```

**Option C: Repo with manual override**
```yaml
research:
  - repo: "Dr-Aniekan-Udo/future-paper"
    autoSync: true
    featured: true
    priority: 3
    thumbnail: "/research/custom-thumb.jpg"
    venue: "Override venue"
```

### Thumbnail Discovery Priority

For projects, the script searches in this order:
1. `thumbnail.{png,jpg}` (repo root)
2. `assets/thumbnail.{png,jpg}`
3. `images/thumbnail.{png,jpg}`
4. `assets/preview.{png,jpg}`
5. `docs/cover.{png,jpg}`
6. `.github/preview.{png,jpg}`
7. `screenshot.{png,jpg}`
8. `banner.{png,jpg}`

If none found → `default-thumbnail.svg`

### Thumbnail Specifications

| Section | Recommended Size | Aspect Ratio | Format |
|---------|------------------|--------------|--------|
| **Projects** | 1280×720px | 16:9 | PNG or JPG |
| **Research** | 1200×630px | 1.91:1 | PNG or JPG |
| **Experience** | 800×600px | 4:3 | PNG or JPG |
| **Education logos** | 400×400px | 1:1 | PNG with transparency |

## Automation Details

### `sync-projects.py`

1. Reads `projects.yaml`
2. For each repo:
   - Fetches GitHub API metadata (stars, language, topics, description)
   - Fetches `README.md` from `main` branch (falls back to `master`)
   - Extracts first paragraph or `## Overview` section as excerpt
   - Rewrites relative image paths to absolute GitHub raw URLs
   - Searches for thumbnail in common paths
   - Falls back to `public/default-thumbnail.svg`
3. Generates `src/content/projects/{slug}.md` with frontmatter + full README

### `sync-research.py`

1. Reads `data/research.yaml`
2. For each entry with `autoSync: true`:
   - Fetches `README.md` from repo
   - Parses structured content (Authors, Venue, arXiv, Abstract, Methodology, etc.)
   - Downloads thumbnail if specified
   - Generates `src/content/research/{slug}.md`
3. For manual entries, generates markdown from YAML data

### `sync-content.py`

1. Reads all YAML files from `data/`
2. Validates schema (skips invalid entries with warnings)
3. Generates placeholder SVGs for missing photos/logos
4. Outputs `src/data/content.ts` — typed TypeScript data for components

## Troubleshooting

### Build fails locally

```bash
# Ensure venv exists and has deps
uv venv .venv --python 3.12
uv pip install -r scripts/requirements.txt --python .venv\Scripts\python.exe

# Sync all content
npm run sync:content
npm run sync
npm run sync:research
```

### Build fails on GitHub Actions

- Check `projects.yaml` and `data/*.yaml` syntax is valid
- Ensure repos in whitelist are public
- Verify `GITHUB_TOKEN` has sufficient permissions (read repos)

### Thumbnails not appearing

- Add a `thumbnail.png` or `thumbnail.jpg` to the repo root or `assets/` folder
- For research repos, specify `**Thumbnail:** assets/thumbnail.jpg` in README
- Run `npm run sync` or `npm run sync:research` to re-fetch

### Local dev errors

- Run `npm run sync:content` first — components need `src/data/content.ts`
- Run `npm run sync` — Astro content collections need the `.md` files
- Ensure Node 18+ and Python 3.10+ are installed
- Ensure `.venv` exists with `pyyaml` installed

### Content not updating

- Edit the YAML file in `data/`
- Run `npm run sync:content`
- Restart dev server if needed
